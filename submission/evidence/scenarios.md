## 历史 OpenDev 执行证据

三个场景均使用 claude-opus-5-5。下列为实际模型发起的动作摘要，其他字段见 JSON。此处的历史执行与公开版页面上的本地快捷演示是不同证据。

- A：分析 BOM → 查询供应 → 模拟涨价 → 拆单规划 → 独立验收 → 变更报告。
- B：分析 BOM → 单供应商规划 → 独立验收失败 → 拆单重规划 → 独立验收仍失败 → 变更报告。
- C：分析 BOM → 拆单优化 → 独立验收预算失败 → 变更报告。

历史 B 首轮原生工具回传收到 HTTP 400 后，控制器继续使用严格 JSON Schema 动作。随后模型根据真实工具结果做了一次重规划。阶段三另有 Chromium 截图记录真实 OpenDev 任务，其中 10 台方案通过独立验收并进入待审批，该任务没有发生重规划。
