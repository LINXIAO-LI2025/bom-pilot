# BOM-BOM队 · A3 竖版海报说明

- **队名**：BOM-BOM队。
- **定位**：面向 AI 硬件产品团队的采购决策工作台。从已录入的 BOM 和报价生成可验收、可追溯的采购建议。
- **核心优势**：Agent 根据目标选择工具；确定性工具计算；独立验收后重规划；保留待审批状态及失败原因。
- **流程**：BOM、报价与约束 → 模型选工具 → Python 计算 → 独立验收 → 待审批方案或受阻原因。验收失败回传模型，最多三次重规划。
- **资产**：cost-chart.png 为真实成本页图表裁切；studio-qr.png 指向公开空间。缺料条形图按历史真实工具数据绘制，两次分配量为 80 和 160，需求 200。
- **印刷**：A3 竖版 297 × 420 mm。PDF 为正式印刷稿，poster.html 为可修改源文件。
